# Quant Factor Lab —— 多因子 Alpha 挖掘与研究回测框架

一个用于横截面股票研究的多因子 Alpha 挖掘与回测框架：因子构建 → 统计假设检验 → 多重检验校正 → 因子挖掘 → 合成因子构建 → 样本外多空回测。

[English README → README.md](README.md)

---

## 概述

流水线消费每日每股的 **价格 / 成交量 / 市值 / 盈利收益率（Earnings Yield）** 面板，依次执行：

1. 构建精选因子库（动量、反转、波动率、特质波动率、规模、价值、流动性）；
2. 对每个因子做 IC / Rank-IC / ICIR / t 统计量检验，p 值从第一性原理实现（无 scipy 依赖）；
3. 对全体候选因子做 **BHY-FDR** 多重检验校正（在检验任意相依的保守假设下控制错误发现率）；
4. 挖掘额外候选因子，走同一套检验流程；
5. 对 FDR 存活因子构建 **Rank 均值合成因子**；
6. 在 **样本外多空回测** 中评估合成因子，计入交易成本与换手率。

仓库内置一个带 *植入* alpha 结构与两个植入噪声特征的合成数据生成器，使整套统计机制可对照已知真值验证；另提供 **真实数据适配器**（Yahoo Finance），同一流水线可直接跑真实行情。

## 功能

- **精选因子库（9 个）**：动量（12-1、6-1）、短期反转、已实现波动率、特质波动率、对数市值、盈利收益率、Amihud 非流动性、换手率。
- **统计检验**：均值 IC、Rank-IC、ICIR、t 统计量、双侧 p 值；每个调仓日做横截面 winsorize 与 z-score。
- **多重检验控制**：可配置 q 值的 BHY-FDR；植入的噪声因子被正确拒绝。
- **因子挖掘**：13 个候选（多周期动量、波动率窗口、规模/价值/流动性变体）在样本内以同一 FDR 门槛筛选。
- **合成因子**：FDR 存活者的 Rank 均值（等权），每次调仓刷新；无前视（因子只使用调仓日之前的数据）。
- **回测**：多空五分组组合，双腿按配置的单边 bps 计费，逐期报告换手率；输出回撤 / 夏普 / Calmar / 胜率指标。
- **合成面板**（`synthetic_data.py`）：120 只股票 × 1008 天，植入 alpha（动量 + 价值 − 波动 − 非流动 − 规模）+ 噪声。
- **真实数据**（`data_adapter.py`）：通过 yfinance 下载任意股票池与日期区间，按字段落盘缓存，重跑可离线。

## 运行结果 —— 合成数据验证（seed=42，120 × 1008 天，20 日调仓）

### 精选因子检验（样本内，26 个调仓日；FDR q=0.05）

| 因子 | Mean IC | ICIR | t 值 | 通过 FDR |
|---|---|---|---|---|
| momentum_12_1 | 0.229 | 2.44 | 12.45 | 是 |
| momentum_6_1 | 0.196 | 1.74 | 8.86 | 是 |
| reversal_1m | 0.066 | 0.56 | 2.84 | 是 |
| volatility_20d | -0.140 | -1.22 | -6.23 | 是 |
| idiosyncratic_vol | -0.148 | -1.30 | -6.61 | 是 |
| earnings_yield | 0.116 | 1.48 | 7.55 | 是 |
| turnover_20d | 0.113 | 1.61 | 8.22 | 是 |
| log_market_cap | 0.024 | 0.21 | 1.09 | 否 |
| amihud_illiquidity | -0.046 | -0.33 | -1.68 | 否 |

9 个精选因子中 7 个通过；挖掘池中植入的两个噪声因子被拒绝（noise_a p=0.79，noise_b p=0.06）。

### 样本外回测（9 个调仓日，单边 10bps 成本）

| 策略 | 年化收益 | 年化波动 | 夏普 | 最大回撤 | Calmar |
|---|---|---|---|---|---|
| 多空（7 因子合成） | 50.3% | 6.9% | 7.29 | -1.8% | 28.0 |
| 纯多头 | 4.8% | 15.5% | 0.31 | -11.0% | 0.44 |
| 基准（等权） | -19.0% | 14.7% | -1.29 | -22.0% | -0.87 |

- 合成因子样本外平均 IC = 0.18（t=12.8）。
- `momentum_12_1` 五分组收益严格单调：-1.9% / +0.7% / +1.3% / +2.1% / +3.6%。

## 真实数据模式

```bash
pip install -r requirements-data.txt        # 安装 yfinance
python scripts/run_pipeline.py --real                       # 默认 20 只股票，2019–2024
python scripts/run_pipeline.py --real --tickers AAPL,MSFT,NVDA --start 2019-01-01 --end 2024-12-31
python scripts/run_pipeline.py --real --refresh             # 强制重新下载
```

首次运行会下载并缓存面板（默认缓存目录 `data/yahoo_cache`）；后续运行直接读缓存。真实数据输出带 `real_` 前缀，与合成数据互不覆盖。

默认 20 只大盘股（2019-01-01 → 2024-12-31，1509 个交易日，60 个调仓日 / 45 训练 / 15 测试）的参考结果：

| 策略 | 年化收益 | 年化波动 | 夏普 | 最大回撤 |
|---|---|---|---|---|
| 多空（FDR 存活因子） | 23.2% | 28.1% | 0.83 | -25.8% |
| 纯多头 | 58.5% | 29.0% | 2.02 | -18.5% |
| 基准（等权） | 40.4% | 13.4% | 3.02 | -8.2% |

该股票池中仅 `momentum_6_1` 通过 FDR：20 只超级大盘股横截面离散度天然偏低，框架如实呈现而非强行制造显著性。

## 方法论

- **无前视偏差**：每个因子只用其调仓日之前的数据；前向收益在调仓日之后测量。
- **每个调仓日 Winsorize + 横截面 z-score**：对离群值稳健、跨日期可比。
- **BHY-FDR**：在检验任意相依的保守假设下控制错误发现率；校正所用的因子数为当前候选集（精选或挖掘）的检验个数。
- **交易成本**：每次调仓按双腿总换手计费，并报告换手率以便评估容量。
- **合成真值**：alpha 结构为植入，因此下游每个统计量（FDR 存活、IC、回测盈亏）都能对照生成器输入核对。

## 配置

全部参数位于 `quant_factor_lab/config.py`：股票池规模与时间跨度、调仓周期、多空分位宽度、单边成本 bps、FDR q 值、随机种子，以及合成 alpha/波动率结构。

## 局限

- 合成股票池的植入效应天然较强；真实市场因子信号更弱，框架如实报告。
- 等权五分组；无风险模型、行业中性或仓位管理。
- 样本外窗口较短（合成 9 个 / 真实 15 个调仓日）——夏普数值仅具指示意义，不作估计。
